# Git Learning Notes

## Important Concepts

- Git is a distributed version control system.
- Git tracks changes in files.
- Git maintains commit history.
- Git supports branching and merging.
- Git enables collaboration between developers.

## Commands Practised

| Command | Purpose |
|---|---|
| git clone | Clone a repository |
| git status | Check file status |
| git add | Stage changes |
| git commit | Save changes in Git history |
| git log | View commit history |
| git show | Inspect a commit |
| git diff | Compare changes |
| git blame | Identify line authorship |
| git reset | Move branch history |
| git revert | Reverse a commit |
| git push | Upload commits |

## Practical Learning

All commands are practised using Ubuntu and the Git_Junction repository.

More commands and troubleshooting scenarios will be added as learning progresses.
