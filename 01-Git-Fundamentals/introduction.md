# Introduction to Git

## 1. What is Git?

Git is a free and open-source distributed version control system (DVCS).

It helps developers track changes in source code, maintain version history,
collaborate with team members and manage software development efficiently.

## 2. Why Do We Use Git?

- Track changes in source code.
- Maintain complete project history.
- Collaborate with multiple developers.
- Restore previous versions when required.
- Create branches for new features and bug fixes.
- Manage code changes across development environments.

## 3. Key Features of Git

| Feature | Description |
|---|---|
| Distributed | Every developer has a local repository |
| Version History | Tracks committed changes |
| Branching | Supports parallel development |
| Merging | Combines changes from different branches |
| Collaboration | Supports sharing changes |
| Offline Support | Allows local commits without internet |

## 4. Git vs GitHub

**Git:**
- A distributed version control system.
- Installed and used on local machines.
- Tracks file changes and commit history.

**GitHub:**
- A cloud-based platform for hosting Git repositories.
- Supports collaboration and code reviews.
- Provides Pull Requests, Issues and Actions.

## 5. Benefits of Git in DevOps

- Enables source code management.
- Supports CI/CD pipeline integration.
- Helps teams collaborate.
- Provides traceability of code changes.
- Supports rollback and release management.

## 6. Important Git Terminology

| Term | Meaning |
|---|---|
| Repository | Location where Git tracks project history |
| Commit | Recorded snapshot of changes |
| Branch | Independent line of development |
| Merge | Combines changes from branches |
| Clone | Creates a local copy of a repository |
| Push | Uploads local commits to remote |
| Pull | Fetches and integrates remote changes |
| Staging | Prepares changes for a commit |
